# MERN App

A web application project with a React frontend and a Node.js/Express backend.

## Project Structure

- `frontend/` – React application built with Create React App.
- `backend/` – Node.js and Express server providing API endpoints.

## Getting Started

### Frontend

1. Open a terminal in the `frontend` folder.
2. Run `npm install`.
3. Run `npm start`.

### Backend

1. Open a terminal in the `backend` folder.
2. Run `npm install`.
3. Run `node server.js`.

The backend server runs on port 5000.
